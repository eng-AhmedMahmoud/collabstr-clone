3 · API brief (docs-verified)

Shape & limits

  • GET/POST hypeauditor.com/api/method/<method>, JSON
  • Auth headers: x-auth-id + x-auth-token
  • Use v=2 (v=1 deprecated Aug 2024)
  • Rate limit: 100 requests/min (error 6 = too many)
  • Reports async: same endpoint returns the report if ready, else queues it — poll (no webhook documented)
  • report_state: READY vs READY_LOW_CONFIDENCE (low audience activity)
  • highDemand:true = HA overloaded, slower generation

Endpoints

  • Report per channel — IG, TikTok, YouTube, Twitch, X, Snapchat (auditor.snapchat?channel=)
  • Discovery (auditor.search) — IG/TikTok/YouTube/Twitch/X · not Snapchat
  • Metrics History (auditor.instagramHistory) — unlocks the report; history only from DB-add date
  • Report Connections (auditor.reportConnections) — links accounts across networks (incl. Snapchat=7)
  • Suggester · Lists · Campaign Management

What the report returns (and doesn't)

  • returns audience_type = real / influencers (infs) / mass-followers / suspicious → the fake-follower breakdown.
  • returns demography (age/gender), location, blogger_rankings (country), follower/following growth charts, comment sentiment (pos/neu/neg), likes-spread, likes-comments ratio, ER benchmarks. Audience demographics & authenticity = advanced report only.
  • derive Quality Audience & Authentic Engagement are NOT returned — compute: Quality Audience = followers × (audience_type.real + audience_type.infs).
  • confirm Whether the composite AQS (1–100) is a field, or must be reconstructed — asked (Q1).

Credits & caching (cost model)

  • Advanced report = 1 report credit; mini report = 1 mini credit. Failed generation refunds the credit (check restTokens).
  • Report cached 12 months; a re-check after 365 days = 1 credit (so in-year re-checks don't add cost — budget on unique creators/year).
  • Snapchat: nasa report is free (use it to test). Report cached 1 year, same as IG.

Hard limits / error codes

Rejected outright (returns error, no analysis): 31 <1,000 followers · 30 private · 33 hidden · 34 suspended · 37 restricted · <1 post. Snapchat: rejected if channel not found / no videos / no views. Also: 26 not enough credits, 27 no API access, 25 service unavailable, 16 not found.

5 · Pricing

API is credit-based & quote-only. Documented unit: 1 report = 1 credit (advanced) / 1 mini credit (mini); the per-credit price is negotiated (Victoria confirmed API pricing differs from Browser packages). Public Browser tiers (not the API): ~$299/mo Basic, ~$499/mo Pro, Enterprise quote.

3 · موجز الـ API (مُوثَّق وفق الوثائق)

البنية والحدود

  • GET/POST hypeauditor.com/api/method/<method>، بصيغة JSON
  • ترويسات المصادقة: x-auth-id + x-auth-token
  • استخدم v=2 (النسخة v=1 أُوقفت في Aug 2024)
  • حدّ المعدّل: 100 طلب/دقيقة (خطأ 6 = عدد الطلبات كبير جدًا)
  • التقارير غير متزامنة (async): يعيد نفس الـ endpoint التقرير إن كان جاهزًا، وإلا يضعه في قائمة الانتظار — استعلِم دوريًا (poll) (لا يوجد webhook موثّق)
  • report_state: READY مقابل READY_LOW_CONFIDENCE (نشاط جمهور منخفض)
  • highDemand:true = HA محمّلة بأقصى طاقتها، توليد أبطأ

نقاط النهاية (Endpoints)

  • Report لكل قناة — IG، TikTok، YouTube، Twitch، X، Snapchat (auditor.snapchat?channel=)
  • Discovery (auditor.search) — IG/TikTok/YouTube/Twitch/X · لا يشمل Snapchat
  • Metrics History (auditor.instagramHistory) — يفتح التقرير؛ السجلّ يبدأ فقط من تاريخ الإضافة إلى قاعدة البيانات
  • Report Connections (auditor.reportConnections) — يربط الحسابات عبر الشبكات (بما فيها Snapchat=7)
  • Suggester · Lists · Campaign Management

ما الذي يعيده التقرير (وما لا يعيده)

  • يُعيد audience_type = real / influencers (infs) / mass-followers / suspicious ← تفصيل المتابعين المزيّفين.
  • يُعيد الديموغرافيا (العمر/الجنس)، الموقع، blogger_rankings (الدولة)، مخطّطات نمو المتابعين/المتابَعين، مشاعر التعليقات (إيجابي/محايد/سلبي)، توزيع الإعجابات، نسبة الإعجابات إلى التعليقات، معايير معدّل التفاعل. ديموغرافيا الجمهور وأصالته = في التقرير المتقدّم (advanced) فقط.
  • يُشتقّ Quality Audience وAuthentic Engagement لا يُعادان — احسب: Quality Audience = followers × (audience_type.real + audience_type.infs).
  • تأكيد هل درجة AQS المركّبة (1–100) حقلٌ مُعاد، أم يجب إعادة بنائها — مطروح (السؤال 1).

الأرصدة والتخزين المؤقّت (نموذج التكلفة)

  • التقرير المتقدّم = رصيد تقرير واحد؛ التقرير المصغّر (mini) = رصيد mini واحد. التوليد الفاشل يُعيد الرصيد (تحقّق من restTokens).
  • التقرير مُخزَّن مؤقتًا 12 شهرًا؛ إعادة الفحص بعد 365 يومًا = رصيد واحد (لذا عمليات إعادة الفحص خلال السنة لا تضيف تكلفة — احسب على أساس صنّاع المحتوى الفريدين/سنويًا).
  • Snapchat: تقرير nasa مجّاني (استخدمه للاختبار). التقرير مُخزَّن مؤقتًا سنة واحدة، مثل IG.

الحدود الصارمة / رموز الأخطاء

مرفوض تمامًا (يُعيد خطأً، دون تحليل): 31 أقل من 1,000 متابع · 30 خاص · 33 مخفي · 34 موقوف · 37 مقيّد · أقل من منشور واحد. Snapchat: مرفوض إذا لم تُوجد القناة / لا توجد مقاطع فيديو / لا توجد مشاهدات. أيضًا: 26 أرصدة غير كافية، 27 لا يوجد وصول إلى الـ API، 25 الخدمة غير متاحة، 16 غير موجود.

4 · التوافق مع العربية / السوق السعودي

  • نعم دولة صانع المحتوى (blogger_rankings، location) + ديموغرافيا الجمهور متوفّرة في التقرير المتقدّم ← الاستهداف السعودي قابل للتصفية والتقرير. تفصيل لغة الجمهور = قيد التأكيد في الرسالة (السؤال 3).
  • نعم تقرير Snapchat موجود (حاسم — نحو 90% من السعوديين بين 13–34 عامًا) ويتوفّر له اختبار nasa مجّاني.
  • فجوة Discovery لا يغطّي Snapchat — ستوفّر صنّاع محتوى Snapchat بنفسك، ويُستخدم الـ API لتقاريرهم فقط (السؤال 4).
  • تأكيد معالجة العربية / اللهجة السعودية في Comments Authenticity + مشاعر التعليقات غير مُوثّقة (السؤال 3).

5 · التسعير

الـ API قائم على الأرصدة وبعرض سعر فقط. الوحدة المُوثّقة: 1 تقرير = 1 رصيد (advanced) / 1 رصيد mini (mini)؛ سعر الرصيد الواحد يُتفاوَض عليه (أكّدت Victoria أنّ تسعير الـ API يختلف عن باقات Browser). أسعار Browser العامة (وليست الـ API): نحو 299$/شهر Basic، نحو 499$/شهر Pro، وEnterprise بعرض سعر.

مرجع معيار مقارنة: واجهة Discovery API المماثلة من Modash ≈ 0.45$ لكل تقرير جمهور، بحدّ أدنى نحو 16,200$/سنويًا. استخدمه للتحقّق من معقولية عرض سعر HypeAuditor لكل رصيد.
